# 🚦 Meus Projetos de Arduino - SENAI Itatiba

Este repositório contém os projetos desenvolvidos durante o curso de **Programação e Interação da Plataforma Arduino** no **SENAI Itatiba**, combinando lógica de programação em C com eletrônica aplicada.

---

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** C/C++ (Arduino)
- **Hardware:** Arduino Uno, LEDs, Botões, Protoboard
- **Software:** Arduino IDE, VS Code

---

## 📁 Projetos

### 💡 Cascata de LEDs
Sequência de LEDs acendendo e apagando em cascata, simulando um efeito de onda.
Conceitos praticados: saídas digitais, loops, temporização com `delay()`.

---

### 🔁 Controle de LED com For
Controle do brilho de um LED utilizando estrutura de repetição `for`.
Conceitos praticados: PWM, `analogWrite()`, estruturas de repetição.

---

### 🎛️ Controle de Velocidade com Botão
Controle de velocidade (brilho) de um LED via botão físico, com lógica de debounce.
Conceitos praticados: entradas digitais, debounce, PWM, controle por botão.

---

### 🚦 Semáforo Duplo
Simulação de dois semáforos sincronizados com 6 LEDs e temporização entre os estados.
Conceitos praticados: lógica de temporização, saídas digitais múltiplas, sincronização de estados.
